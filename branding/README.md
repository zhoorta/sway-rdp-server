# Waydesk logo

Three stacked windows, the front one lit in copper: a desktop of windows, and the session that is open and in front. In the wordmark
"way" is copper and "desk" is ink. The windows are cut out of each other with masks, so the files work on any background.

| File | Use |
|---|---|
| `waydesk-logo.svg`, `waydesk-logo-dark.svg` | mark and wordmark, for light and dark backgrounds |
| `waydesk-mark.svg`, `waydesk-mark-dark.svg` | the mark alone |
| `waydesk-icon.svg` | square app icon / favicon source (dark tile) |
| `two-lines/` | "way" over "desk" beside the mark, for narrow places such as a sidebar or a header |

PNG versions are in `png/`, with transparent backgrounds: `waydesk-logo.png` and `waydesk-logo-dark.png` (512 high),
`waydesk-mark.png` and `waydesk-mark-dark.png` (512x512), and `icon-16.png` up to `icon-1024.png` (16, 32, 48, 64, 128, 180, 256,
512, 1024) for favicons, the Apple touch icon (180) and app stores.

Colours: ink `#14171d`, paper `#f2eee8`, copper `#c4661a` (`#f29a4c` on dark). The wordmark is outlined from Outfit, one weight for both words
(SIL Open Font License 1.1), so no font is needed to show the files. Waydesk is a working name: no trademark clearance has been done.

## Other layouts of the wordmark

- `two-lines/`: "way" over "desk" beside the mark (see above).
- `joined/`: "way—desk", a copper wire with a node joining the two words, no mark. Suits a banner or a tagline. It can also be read as
  hyphenated, so the stacked-windows logo stays the main one.

Each has SVG files for light and dark backgrounds and transparent PNGs (`png/`, 8x size).

## Alternatives

- `alternatives/d-wire/`: the first logo, a D-shaped screen with a copper wire to a lit node (same file names as above).
- `alternatives/`: a monitor whose screen is crossed by a wire in the shape of a W (`waydesk-monitor-*.svg`, PNGs in `alternatives/png/`). It
  is the more literal "remote desktop" picture, but it turns into a blob at 16 and 24 pixels.
