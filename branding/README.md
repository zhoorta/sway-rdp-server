# Deskwire logo

A screen shaped like a D, with a copper wire through its edge to a lit node: the session, connected.

| File | Use |
|---|---|
| `deskwire-logo.svg`, `deskwire-logo-dark.svg` | mark and wordmark, for light and dark backgrounds |
| `deskwire-mark.svg`, `deskwire-mark-dark.svg` | the mark alone |
| `deskwire-icon.svg` | square app icon / favicon source (dark tile) |

Colours: ink `#14171d`, paper `#f2eee8`, copper `#c4661a` (`#f29a4c` on dark). The wordmark is outlined from Bricolage Grotesque
(SIL Open Font License 1.1), so no font is needed to show the files. Deskwire is a working name: no trademark clearance has been done.
