Questions and answers

Short answers, with a link to the page that has the rest.

Do I need a GPU?

No. Without one, everything is drawn and encoded on the CPU. With one (Intel, NVIDIA, AMD should work) the desktop is drawn on it and the picture is encoded by the chip, which leaves the CPU to your programs. The GPU page has the numbers.

What happens when I close the RDP window?

Nothing: the session is a systemd unit of the account and keeps running, so reconnecting gives you the same windows. A second login from the same account takes the running session over.

Why Sway?

Each session needs a desktop that can run headless, one per account, and be captured and scripted. Sway is a small Wayland compositor that does that, and it is what the picture sent over RDP is captured from. Windows are floating with title bars, so it feels like a desktop, not a tiling window manager.

Which applications run?

Wayland and X11 applications, from the distribution or from Flathub. X11 programs run through XWayland, one server per account. Checked: Chromium, VS Code, LibreOffice, Obsidian, Slack, GNOME Text Editor, GIMP, Zed, Blender, Kdenlive, darktable. waydesk-setup offers browsers, office, developer and creative applications.

How many users fit on one server?

On an 8 GB server 7 to 8 users fit with Chromium, Calc and VS Code open and left idle; people who are working use more, about 1.6 GB each on the 23 GB server we measured with active users. Memory is the limit, and a new session is refused rather than slowing everyone down. See Limits and status.

Is it safe to put on the internet?

Not with the port published: the login is a password with no second factor. Use an SSH tunnel or a VPN, which are both a few commands. VPN and securing access says what protects the login.

Which RDP clients work?

The Windows App on macOS, mstsc on Windows 11 and FreeRDP were tried. The list, with what did not work, is on Limits and status.

What does it cost, and who makes it?

It is free software, MIT or Apache-2.0, written by José Mendonça. Commercial support and setup are offered by StackCare.

Can I see how it is built?

Yes: Architecture draws the three parts, Measurements shows how each figure was taken, and the source is on GitHub.
