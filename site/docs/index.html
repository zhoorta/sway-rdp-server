All pages

The home page is the overview; these pages go deeper. Each is a file in the repository, written from what was run on real servers.

/start/–□✕

Getting started

Install Waydesk on Debian 13 or Ubuntu 26.04, make the first administrator, connect, and add more people. About ten minutes from a fresh server.

/connect/–□✕

Connect

The ways an RDP client can reach a Waydesk server: an SSH tunnel, the local network, a WireGuard VPN, and certificates a client can verify.

/vpn/–□✕

A VPN with WireGuard

Put the RDP port behind a WireGuard VPN with three commands: init, add a client, scan the QR code. A key per device and one UDP port open.

/cli/–□✕

The command line

Every waydesk-admin command with its real output: accounts, sessions, limits, status and --watch, access, certificates and the VPN.

/gpu/–□✕

Using a GPU

What Waydesk does with a GPU (Intel, AMD, NVIDIA), how to set it up, how to see what each session runs, what happens when it fails, and what was measured.

/architecture/–□✕

Architecture

How a login reaches a session, what each of the three parts may do, and how the capture and the encoder work.

/measurements/–□✕

Measurements

Memory per user, capacity of an 8 GB server, bandwidth on a bad link and the GPU figures, each with its method.

/security/–□✕

Security

What the daemon, the helper and the sessions may do, what is checked at login, and what was reviewed.

/reference/–□✕

Reference

The tested systems, clients, files, ports and settings of Waydesk, in tables.

/help/–□✕

When something is wrong

What to check when a client cannot connect, a session is refused, the picture is slow or wrong, or the GPU is not used. Where the logs are.
