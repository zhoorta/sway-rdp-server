Source code and licences

Waydesk is MIT or Apache-2.0 (source on GitHub); so are the other programs we build: sway, wlroots, DankMaterialShell, danksearch and dgop. Three copyleft programs are in the repository as binaries, and their source is offered here, from the same place as the packages, at no charge:

  • matugen 4.2.0 (GPL-2.0-or-later), built unmodified from the upstream tag, with its Rust crates
  • quickshell 0.3.0 (LGPL-3.0-only), built unmodified from Debian's copy of the release
  • pcmanfm-qt (GPL-2.0-or-later): the Debian 13 and Ubuntu 26.04 source packages and our two patches (they remove menu entries)
$ curl -fsSL https://waydesk.dev/apt/source/README

Every file is listed with its checksum in SHA256SUMS; the folder has the archives. Each package also carries its licence under /usr/share/doc/<package>/copyright.
